. Confirm `response`, `model`, `backend_scope` and `model_artifact_digest` are absent. Find only `router.injection.blocked` for this request.
. Match the request-correlated simulated dispatch record: zero OVMS calls. A missing answer alone would not establish zero calls.

*Blocked live procedure:* run the supplied injection test through the qualified boundary and inspect trustworthy request-correlated backend traces or a call counter. Require a fresh denial receipt when the ledger is healthy.
A known denial stays denied if its audit write fails; unavailable evidence fails the receipt checkpoint. Do not invent an acknowledged hash.
The reviewed current API normalizes rejection differently; the 403 result is the proposed contract illustrated here.

== Learner checkpoint
