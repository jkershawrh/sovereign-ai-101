. Record the export exception by filename and close the learner guide. If you stopped early, record which rehearsal checkpoints remain incomplete.

== Blocked live cleanup procedure

Before provisioning, inventory ownership of namespace, jobs, deployments, services, routes, ConfigMaps, Secrets, PVC/PV and backing NFS directory, session credentials, fault state, local temporary files and port-forward processes.
Keep shared model/platform resources and neighboring tenants separate.
After evidence capture: restore scoped fault state, revoke session access, clear UI/cache, stop owned processes, remove only disposable owned resources, wait for deletion, and verify storage reclamation and absence of residue.
Use idempotent cleanup that fails explicitly while anything owned remains; verify a neighboring-tenant sentinel is unchanged.
Namespace deletion alone proves neither NFS removal nor credential revocation.
Never delete individual records from a shared chain to manufacture cleanup; use disposable tenant storage.
Retention exceptions that leave owned lab data invalidate strict zero-residue acceptance. Zero residue is not a forensic backup-erasure claim.
